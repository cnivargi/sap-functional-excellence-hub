# Project Governance

## Roles
- **Contributor:** Submits scenarios, configuration guides, troubleshooting playbooks, or tooling via Pull Requests.
- **Functional Reviewer:** Validates business accuracy, cross-module impact, release applicability, and accounting/document flow correctness.
- **Maintainer:** Oversees repository architecture, JSON schemas, CI quality gates, licensing compliance, and formal releases.

> **AI Governance Policy:** AI tools may assist in drafting, structuring, and discovering release changes, but **no AI agent may autonomously set `status: reviewed` or merge functional guidance**.
