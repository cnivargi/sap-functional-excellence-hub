# SAP Functional Glossary

| Term | Definition |
| :--- | :--- |
| **ACDOCA** | Universal Journal physical line-item table in SAP S/4HANA Finance. |
| **CVI** | Customer-Vendor Integration synchronizing Business Partner (`BUT000`) with Customer/Vendor tables. |
| **VSiT** | Valuated Stock in Transit used in Advanced Intercompany Sales (`5D2`). |
