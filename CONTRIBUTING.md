# Contributing to SAP Functional Excellence Hub

Thank you for helping build an open, verifiable knowledge engineering platform for SAP functional consultants.

## Non-Negotiable Rules
1. **No Confidential or Proprietary Material:** Never submit client documents, client screenshots, real company data, personal data, or copied proprietary SAP training manuals/OSS note text.
2. **Pull Requests Only:** Direct commits to `main` are prohibited. All contributions go through PR review and automated CI checks.
3. **Honest Verification Status:** New contributions must start with `status: draft` and `last_verified: null` until verified by a human Functional Reviewer.
4. **Distinguish Behavior Clearly:** Always separate *Standard SAP behaviour*, *Release/deployment dependencies*, *Recommended practice*, and *Illustrative configuration*.
